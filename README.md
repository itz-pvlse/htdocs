> A comprehensive web-based automotive management platform for vehicle history tracking, dealer listings, garage operations, and vehicle rentals.

---

##  Live Application

Access the live platform here: **[autolog.co.ke](http://autolog.co.ke)**

---

##  Features

- **Automotive Management:** Track detailed vehicle specifications, service records, and maintenance histories.
- **Dealer Ecosystem:** Interactive dealer dashboard for vehicle listing creation, inventory updates, and inquiries.
- **Garage & Service Hub:** Dedicated garage management suite with specialized wallet and commission tracking engines.
- **Vehicle Rentals:** Integrated rental workflows for viewing, reserving, and managing fleet options.
- **Responsive UI:** Modern, user-friendly interface optimized across desktop and mobile devices.

---

##  Built With

- **Backend:** PHP (OOP architecture, modular service design)
- **Database:** MySQL
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap / Tailwind CSS
- **Tools & Utilities:** Composer, Git

##  Getting Started

Follow these steps to set up and run AutoLog on your local development environment.

### Prerequisites

Ensure you have the following installed on your machine:
- Web server (e.g., Apache/Nginx via XAMPP, WAMP, or Laragon)
- PHP `7.4` or higher
- MySQL / MariaDB Database
- Composer
